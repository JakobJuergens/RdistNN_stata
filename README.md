# RdistNN_stata

`RdistNN_stata` is a Stata package for distributional nearest-neighbor (DNN)
local estimation and pointwise conditional Z-estimation. It is the Stata
companion to the R package
[RdistNN](https://github.com/JakobJuergens/RdistNN) and the paper
[Robust Inference for Conditional Z-Estimation via Distributional Nearest Neighbors](https://github.com/JakobJuergens/Cond_Z_Estimation).

The current package exposes four user-facing commands:

| Command | Purpose |
|---|---|
| `np_dnn` | Pointwise nonparametric regression at a target covariate profile |
| `cate_dnn` | Pointwise conditional average treatment effect with user-supplied nuisance functions |
| `plqr_dnn` | Localized PLQR orthogonal moments at a supplied coefficient vector |
| `weights_dnn` | Utility for computing and exporting exact DNN rank weights |

Stata 17 or later is required.

## Installation (development)

Clone or copy this repository, then run `dev-setup.do` once per Stata session
to add `src/` to the adopath:

```stata
do "path\to\RdistNN_stata\dev-setup.do"
```

To make the adopath addition permanent across sessions, add the `adopath ++`
line to your `profile.do` (find it with `di c(sysdir_personal)`).

## Quick start

```stata
* Simulate data
clear
set obs 1000
set seed 42
gen x1 = rnormal()
gen x2 = rnormal()
gen e  = invlogit(0.5*x1 - 0.5*x2)
gen D  = (runiform() < e)
gen m0 = 1 + x1 - x2
gen m1 = m0 + 0.5 + 0.5*sin(x1)
gen Y  = m0 + D*(m1 - m0) + rnormal()*0.5

* Estimate CATE at the origin with oracle nuisances
cate_dnn Y, treat(D) x(x1 x2) x0(0 0) propensity(e) m0(m0) m1(m1)

* Local PLQR moments at a supplied beta with oracle nuisances
gen md1 = 0.3*x1 - 0.2*x2
gen md2 = -0.1*x1 + 0.4*x2
gen d1  = md1 + rnormal()*0.4
gen d2  = md2 + rnormal()*0.4
gen q   = 0.25*x1 - 0.15*x2
gen Yq  = d1 - 0.5*d2 + q + rnormal()*0.5
plqr_dnn Yq, x(x1 x2) x0(0 0) d(d1 d2) q(q) md(md1 md2) ///
    beta(1 -0.5) tau(0.5)

* Inspect DNN weights
weights_dnn x1 x2, x0(0 0) k(5) generate(w)
summarize w
```

## Verification

Static package checks:

```powershell
bash tools/ci/pkg_check.sh
bash tools/ci/archive_check.sh archives/source.zip
git diff --check
```

Full Stata runtime tests on a machine with Stata 17 or later:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/ci/stata_runtime_check.ps1
```

Fresh install smoke test, using isolated temporary `PLUS` and `PERSONAL`
directories:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/ci/stata_install_check.ps1
```

Both Stata helpers accept `-StataExe` to override executable discovery.  On the
current Windows development machine, StataNow 19 is discovered as
`C:\Program Files\StataNow19\StataSE-64.exe`.

`archives/source.zip` is generated by the package snapshot workflow.  Do not
edit it by hand; after source or manifest changes are pushed, the workflow
validates and regenerates that archive.

## Notes

- `cate_dnn` requires user-supplied propensity scores and both treatment-arm
  outcome models, `m0()` and `m1()`. These may be oracle values or first-stage
  estimates; Neyman orthogonality protects against first-stage bias at the
  local effective-sample-size scale.
- `plqr_dnn` requires user-supplied `q()` and `md()` nuisance variables and a
  fixed `beta()` vector. It reports localized PLQR moments in `e(b)` and their
  full jackknife covariance in `e(V)`; it does not solve for `beta`, estimate
  nuisances, or perform GMM.
- `k` controls the number of nearest neighbors, while `s` is the DNN kernel
  order. The default `s(0)` uses the undersmoothing rule
  `floor(n^((kx+1)/(kx+2)))` from the paper.
- Use `distance(mahalanobis)` when covariates are strongly correlated. The
  jackknife keeps the full-sample covariance metric fixed across leave-one-out
  deletions.
- Standard errors are computed with the fast rank-shift jackknife, exploiting
  the L-statistic structure of the DNN estimator.
