# R-to-Stata Test Crosswalk

This file records which high-value `RdistNN` contracts are enforced by the
Stata suite. It is a selection guide, not a claim that every R-specific API has
a Stata equivalent.

## Shared contracts

The fixed cross-language dataset and values in `test-r-parity-priority.do` are
generated by `tools/generate_r_priority_fixtures.R` from the sibling R source.
The Stata runtime suite deliberately does not require R.

CLATE reference values are separately regenerated with
`Rscript tools/generate_r_clate_fixtures.R`. RdistNN remains authoritative:
do not adjust fixtures to match a Stata discrepancy. The R API supplies
marginal component/ratio covariance and retained paired deletions; the fixture
uses those deletions to compute Stata's joint cross-target covariance. Stata's
full-target `e(estimates)`/`e(se_targets)` preserve R's missing-target behavior;
its `e(b)` omits undefined target coefficients because Stata rejects missing
coefficient posts. The CATE-compatible 25-column diagnostic schema uses
instrument arms for CLATE, and the public CLATE tables relabel them.

## Shared reporting and interface coherence

`test-estimator-reporting.do` checks actual table shapes/values, fit/replay,
confidence levels, canonical full-target matrices, `nose`, zero variance,
undefined CLATE targets and legacy CATE/NP result replay. Reference six-column
summaries at 90 and 95 percent come from
`tools/generate_r_reporting_fixtures.R` and `fixtures/r_reporting_fixtures.do`.
CATE and CLATE paired-signal summaries call R's actual CATE and affine-ratio
summary methods. NP uses its R estimate/SE and the shared normal convention;
R NP has no summary method. The generator converts R infinities to missing
because Stata matrices cannot represent them.

`test-estimator-diagnostics.do` checks common target/candidate grammar,
localization identities/fields, original row ordering, scientific extensions,
saved data and state preservation. `test-estimator-plots.do` checks common
options, selected data/counts, dashboard metadata, batch/candidate combinations,
sample value/order guards, unavailable targets and graph export. Rendering is
also inspected from exported SVG/PNG files. R ggplot object internals are
outside this functional-interface comparison.

## Premerge audit coverage

The premerge audit extends these checks with 35 seeded R cases generated by
`tools/generate_r_clate_audit_fixtures.R`. Generation asserts independent
subset-enumeration and integrated-beta-weight deletion oracles, including the
full interleaved component covariance. `test-premerge-clate.do` retains every
target's missing mask and covers off-span singular Mahalanobis geometry,
affine/scale identities, reordered/duplicate targets and infeasible grids.
`test-premerge-postestimation.do` compares all stored estimation values and
matrix stripes plus caller data, genuine return membership, reconstructed
contributions, cold restores, selectors and confidence bounds across families.
`tests/ci/test_premerge_audit.py` exercises real verification wrappers with a
mocked process to reject stale logs, echoed markers and nonzero exits.
See [the audit receipt](../docs/premerge-testing-audit.md) for executed scope
and platform/version limits.

## R-only contracts

The following R tests do not currently map to a Stata command and should not be
ported as superficial assertions:

- custom distance, rank-weight, score, and tuning registries;
- TDNN weights, TDNN estimators, and TDNN jackknife paths;
- general local GMM models and IV simulation/replication helpers;
- R container dispatch (`matrix`, `data.frame`, tibble), S3 methods, and
  `predict()` behavior;
- ggplot object internals and `vdiffr` visual snapshots;
- PLQR density-backed coefficient inference at the supplied evaluation vector
  (the current R command also does not perform local root solving);
- PLQR multi-target tuning grids, which are not yet a Stata feature.
- optional affine-ratio confidence-set inversion and R CLATE benchmark/learner
  helpers; the Stata CLATE workflow provides CATE-style pointwise Wald reporting.

When one of these features is added to Stata, promote its corresponding R
contract into the shared table and add deterministic behavioral tests.
