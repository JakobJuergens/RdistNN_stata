# Stata CLATE Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Bring CLATE to parity with the Stata CATE workflow and push the verified feature branch.

**Architecture:** Reuse CATE's validated localization/tuning interface and shared rank-weight functions. A separate paired Mata evaluator owns ratio estimates, joint deletions and covariance. Shared plot builders receive explicit CLATE adapters and labels.

**Tech Stack:** Stata 17 ado/Mata, licensed Windows StataNow 19, R reference fixtures, Python/shell package checks.

**Spec:** `docs/superpowers/specs/2026-10-17-clate-design.md`

## Global Constraints

- Stata 17 minimum; no new dependencies or nuisance fitting.
- Preserve existing estimator/plugin behavior and use supplied predictions.
- Work on feature/clate; commit and push that branch after final verification.
- Paired frozen-score inference; never observation or deletion ratios.
- Missing targets stay visible; finite negative first stages remain computed.

## Review Focus

- Mixed valid/undefined batch targets must retain target identities and valid covariance.
- An exact-zero or cancellation-dominated first stage must never become a zero treatment effect.
- Data changes and restored estimates must not silently mix mismatched score variables.
- Infeasible/duplicate grid orders must retain CATE's metadata and scalar-fit equivalence.
- Perfect compliance and signed paired scores must retain cross-component covariance.
