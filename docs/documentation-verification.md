`feature/clate`, using the R documentation source snapshot

  CATE/regression, weights/tuning, diagnostics/reporting, visualization,

  References explain preferred options, aliases, shapes, metadata, availability,
  selection, export and inference limits rather than assuming an R object API.
- Six standalone seeded examples cover onboarding, all CATE score routes,
  regression, matched weight reconstruction, paper/direct grids, diagnostic

  NP outcome dispersion and paired-signal CLATE forests. The figures are
  generated by the example workflow rather than hand-edited. The dashboard's
  nested tuning labels are compact; the guide recommends a standalone tuning
  panel for detailed target-specific reading.

## Source and scientific checks

The source audit reconciled sample and dimension conventions that differ by
command, including selected-row probability validation, complete cases and
one- versus two-covariate Mahalanobis restrictions. It keeps k, kernel order,
positive support, ESS and physical radii distinct. The guides preserve frozen
nuisances/fixed metrics in delete-one covariance, localization bias and nuisance
stability requirements, pointwise versus simultaneous inference, CLATE
components/statuses and causal-IV conditions, outcome quantiles versus mean
confidence intervals, and PLQR moment versus coefficient uncertainty.

Independent review covered every help, article and example. It identified
and prompted correction of a swapped reason/status ordering in one CLATE help
schema and development links reaching older master-branch test contracts.
The final static package gate also checked that required kernel-order, PLQR
and CLATE inference guardrail wording survived the reference rewrites.
No material finding remained after the corrections and compact-guide/gallery
review. Developer/test files intentionally excluded from the curated source
ZIP use matching feature-branch repository links; shipped articles, examples
and figure assets use portable local links.
